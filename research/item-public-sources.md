# 贝果计划物资图鉴：公开资料核验

核验日期：2026-09-06。范围：已上线的《绝区零》3.1「迷宫诡域：贝果计划 / Enigma of the Labyrinth: Operation Bagel」。这里记录公开来源可支持的事实；完整数据清单应与本项目另行提取的 3.1 配置逐项关联。

## 核验结论

- 找到官方「地图与物品」介绍，以及原作者发布的全图鉴攻略、全物资价值排名视频。官方可读文字没有列出逐项完整物资清单；B 站可索引文字也没有完整转录。因此，本次公开资料核验不能独立证明完整条目总数、全部名称或每件物品的售卖价值。
- **本次核实到的“具体物品在图鉴中播放原作动画”的条目为 0。这个数字表示证据未取得，不表示游戏内没有动态物品。** 搜索结果、封面和图标不能证明动画。没有取得可逐帧检查的原作图鉴片段、动画文件、序列帧或已确认动画资源与物品 ID 的映射。
- 战术道具的使用效果、场景里的实体动作、图鉴预览动画是三件不同的事。骸影有战斗使用效果的文字证据，但不能据此把骸影图标标成「原作动态」。物品名或图标看起来像电视、风扇、发光物，也不足以推断其动态图鉴表现。
- 图鉴 UI 可展示提取到的真实静态图标；原作动效字段宜保留「未核实」。通用 CSS 旋转、呼吸光、浮动或粒子效果只能称页面展示效果，不能称原作动效，也不能用它填补缺失动画。

## 实施建议与缺口

1. 物资清单、图标路径、价格、堆叠数量优先来自本项目的版本固定配置；公开攻略用来交叉验证，不靠文章标题生成完整清单。
2. 每件动效若要标成已核实，至少存 `itemId`、证据页面、原作片段时间范围、观察到的动作，以及版本/来源说明；若只有原始资源，则需确认资源与该物品 ID 的关系及正确的播放方式。
3. PNG/JPEG/WebP 后缀本身不足以证明所有素材都静态；但本篇官方 JPEG 介绍图与普通单帧图标都不能提供原作动画。实际帧数、资源格式、相关配置字段应由素材提取工作进一步核验。
4. 3.2 前瞻和未来赛季轮换资料不混入 3.1 当前清单。没有逐项证据时，页面可写「3.1 配置物资图鉴」和「动效未核实」，避免宣称「已复刻所有原作动效」。

未采信商业转载站的无来源物资名单、搜索摘要自动拼接内容，以及与官方参与门槛/地图事实冲突的攻略。没有找到可单独引用的官方完整动态图鉴素材库。
