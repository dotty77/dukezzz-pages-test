    3.3本赛季「古怪试炼」
    • 古怪试炼：开启古怪卜卜箱获得古怪能量烛，在战术台提交开启，共3轮，每轮1根；从两位邦布教官的方案中选择增幅与奖励。前两轮结束可提前领奖，死亡则失去本次试炼奖励。
    • 烛能芯核：调查内的古怪试炼、古怪卜卜箱每周合计最多获得6个，周期和限定任务另可获取。到古怪回收处出售为赛季硬币，报价每日刷新。
    • 拟态单质X/Y/Z：仅高危，来自随机容器、单质目标和UP调查事件；带本周UP代理人可遇见调查事件。三种各一枚自动合成贵重物品，每次拾取有概率获得侵蚀；撤离后剩余的转为可出售的惰性单质。
    • 图鉴新增56项：7名代理人的战术棱镜与蓝图、玩偶·小光布/仪玄布、辉瓷盘摆件、拟态与惰性单质、古怪能量烛和烛能芯核；旧物品说明与获取途径同步更新。
    试炼领奖与弃考

    入场前留意游戏地图的“可触发试炼”标识。领取的增幅通常持续本次调查，个别即时或临时效果除外。主动弃考不退烛、不能重开，但已完成轮次的累计奖励仍可回战术台领取。

    回收处与周结算

    可去自己、好友、站点成员的回收处，也可用分享码前往其他绳匠。周末未售出的芯核按自己本周最后报价自动出售；其他绳匠来出售时，店主获得5%分成，每周最多1000赛季硬币。

    单质合成与侵蚀

    背包和安全箱中的单质都参与合成，单局可重复。每次拾取有概率获得侵蚀；部分症状可叠加，拾取越多，重度侵蚀概率越高。合成本身不额外增加侵蚀，丢弃或合成也不会清除已有症状，撤离后症状消失。单质目标默认有恶噪护盾，侵蚀突袭更频繁，突袭后有概率追加侵蚀追击；游戏地图会标记其携带种类，击败后需打开残响容器拾取。UP调查事件需激活信标、击败敌人并手动开启残响容器，可任选X/Y/Z一枚。

    3.3限购与临时扩容

    大富豪商店的“古怪限购”仅在3.3期间开放，提供菲林、古怪能量烛和限时配饰“盈月归期”。安全箱临时扩容现有倒计时，3.3结束失效，3.4重置；“狗头保命”在珍品专柜。

    其他体验更新

    游戏图鉴新增各赛季地图的最佳数据与排名；键鼠快捷操作、拖拽滚轮、移动端非战斗交互及物资箱一键使用/丢弃有优化。掉落分布调整不等于容器类型、掉落概率或数量改变。
