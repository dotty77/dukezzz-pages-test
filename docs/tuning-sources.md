# 调频数据与图像来源

DUKE是玩家制作的工具。代理人、音擎、邦布的名称及图像归米哈游 / HoYoverse 等相应权利人所有；本站不是官方服务。

- 导入格式参考 [UIGF 官方标准](https://uigf.org/zh/standards/UIGF.html)，支持范围以导入页说明为准。官方 ZZZ 标准字段使用 `nap`。
- 卡池基础规则、硬保底及当前名单核对自[游戏公开频段列表](https://operation-webstatic.mihoyo.com/gacha_info/nap/prod_gf_cn/gacha/list.json)及其中的官方详情。
- 代理人和音擎的 ID、稀有度、多语言名称映射参考 [Enka Network 数据目录](https://github.com/EnkaNetwork/API-docs/tree/master/store/zzz)。
- 原186张图像来自已安装正式客户端的对应UI纹理；3.2新增7张图标来自Enka所引用的游戏原始CircleIcon / ImagePath资源，保存为本地图像，不使用生成图像替代角色或物品。
- 当前图标目录：60名代理人、100件音擎、33只邦布，共193项，核对版本为3.2.0。目录不是卡池掉落表；下期代理人和非调频音擎可以先收录在图鉴中，不表示目前已能通过调频获得。

分析依据用户导入的已有记录。记录不完整、未包含定向选择或历史规则变动时，不能据此保证完整生涯统计、下一次获取结果或准确的定向保底状态。普通返场与「独家重映 / 音擎回响」为不同频段规则。

## 汇总卡片与大小保底

汇总卡片使用所有已导入频段的实际记录；平均每金只取同频段完整 S 到 S 区间，不将首个 S 之前的缺失起点视作完整周期。UP 指标只统计已核验期次：小保底不歪率排除大保底和此前状态未知的事件；每 UP 平均抽数使用完整 UP 到 UP 区间。暂无法计算的值显示破折号。

本地 `tuning-banners.json` 保留 3.1 的 8 个历史窗口，并增量收录 3.2 上期普通角色/音擎的 4 个分时区窗口，共 12 个。2026-09-09 重新核对 UTC+8（国服、亚服）和 UTC-5（美服）的官方列表及全部上期详情；国服与亚服起止和名单一致。没有使用当前名单回推旧版本，UTC+1 及其他未核验期次不自动推断。

3.2 上期国服、亚服公示时间为 2026-09-09 06:00:00 至 2026-09-30 11:59:59（UTC+8），美服为 2026-09-08 17:00:00 至 2026-09-30 11:59:59（UTC-5）。[官方上期公告](https://zenless.hoyoverse.com/zh-cn/news/165979)说明南宫羽/霓虹妄想属于普通独家/音擎频段，不归为独家重映102或音擎回响103。公示开始值不代表维护实际完成时间；未核实的下期窗口不预填。

3.2 上期的非 UP S 定制池仍为九名候选及对应专武，由玩家从中选择六个；候选包括凯撒、柳、朱鸢，不能只按旧六常驻名单判断“歪”。常驻频段仍按其自身名单处理。A UP 可由玩家自选两个，默认妮可/安东及聚宝箱/旋钻机-赤轴不应直接当作每个账号的历史选择。

3.3 上期国服、亚服公示为 2026-10-21 06:00:00 至 2026-11-11 11:59:59（UTC+8），美服为 2026-10-20 17:00:00 至 2026-11-11 11:59:59（UTC-5），三服名单一致。非 UP S 定制候选仍为同样九名角色及对应九件音擎（2026-10-21 逐项核对三服官方详情的 s_group_customize_items），概率与保底规则未变。下期「答案在风中」「禁罪囚笼」目前只有[3.3 更新公告](https://www.miyoushe.com/zzz/article/79036482)中的名称，下期公示发布前不预填窗口。

[3.2 版本公告](https://zenless.hoyoverse.com/zh-cn/news/166000)列出的喵运当头和「月相」-弦可以通过调频获得；当前公示中「月相」-弦也出现在邦布频段的B级音擎列表。血髓秘匣是城募奖励，图鉴收录不意味着它在调频掉落池内。角色与专武新增关系通过 [Enka 3.2 WeaponId 显式绑定](https://github.com/EnkaNetwork/API-docs/blob/a64e26184903df9d91002a72663b9ba62a710cb7/store/zzz/avatars.json)核对，共47对；专武关系不证明历史UP身份。

在已核验的普通频段中，上次 S 为非 UP 则下次 S 是大保底；上次 S 为 UP 则恢复小保底。普通角色小保底的 UP 比例为 50%，普通音擎为 75%。这表示出 S 时的对象保证，不是下一抽立即出 S。

3.2 上期公示继续确认角色S综合概率1.6%、音擎2%，硬保底90/80。现有从零垫抽、小保底开始的目标UP近似期望仍为角色93.75抽、音擎62.5抽，最坏上限180/160；不用于102/103特殊定向池。赠送自选角色或音擎不作为调频记录，不重置调频保底。

未核对到期次时可以手动补充最后 S 是否 UP；它只影响本页该账号、频段与最后记录的保底提示，不改动原记录，也不混入自动统计。重映 102/103 的福利保底与常规保底独立，记录缺少当期选择和福利状态，不能复用普通频段的最后 S 判断法。


## rng.moe 备份迁入

从 [rng.moe 设置页](https://zzz.rng.moe/zh/settings) 的「备份 → 导出」取得绝区零整站 JSON，本站仅解析 `data.profiles[*].stores["0"].items`。对应公开前端的逐抽结构中，`uid` 是字符串记录 ID，`id` 是物品 ID，`timestamp` 是毫秒时间戳，`rarity` 的 4/3/2 分别为 S/A/B。账号来自简档 `bindUid`，不使用行 `uid` 充当账号；缺少绑定时须在预览补充归属。

频道 1001/2001/3001/5001 对应常驻/独家/音擎/邦布；12001/13001 单独归入复刻角色 102/复刻音擎 103，普通频段中的返场角色继续留在原频段。原站内部 `gacha` 不是官方 `gacha_id`，其预先计算的保底、UP、歪率等不迁入，本站按逐抽记录重新计算。背包 `stores["1"].itemList`、成就和设置不作调频记录。

预览允许核对或选择服务器时区，按绝对时间还原后以 UID 与完整字符串记录 ID 合并；记录内容冲突则整次取消。手动添加的记录、数字型记录 ID、未知频道或不明确的品质会停止迁入并提示，避免静默少算。协议依据 2026-09-11 公开前端及新建空档案导出结构核对，测试使用合成有记录备份，尚未以用户真实有记录备份作端到端验证。

## 链接读取节奏

默认最多两个频段同时读取，可取消“双频段加速”改为顺序读取；同一频段仍逐页使用官方记录 ID 游标推进，每次申请 20 条，实际条数由官方决定。所有频段与重试共用至少 350 毫秒的请求开始间隔，网络等待可以重叠。收到 HTTP 429 响应头后立即全局等待，并将本次读取降低为单路；遵守 Retry-After，不重复延长同一响应的冷却。保留同页最多两次自动重试、取消、成功同步后的增量锚点、完整校验和原子合并。最终失败或取消不保存部分档案。真实耗时取决于网络、卡池记录分布及是否可增量更新，合成测试加速比不代表官方接口实测。
