This is a modified version, not the byte-for-byte upstream script.
Changes include shared read access with a temporary-copy fallback,
chunked cache scanning, deduplicated official URL validation with timeouts,
UTF-8 log handling, version-directory fallback, and clearer progress and
clipboard failure reporting. It is maintained by DUKE and is not endorsed
by rng.moe. The original scripts and their attribution remain unchanged
under vendor/rng-moe/.

For manual use in Windows PowerShell:
  .\get-tuning-link-fast.ps1 -Client cn
  .\get-tuning-link-fast.ps1 -Client os
Optional: -GamePath "C:\path\to\ZenlessZoneZero_Data"
Optional: -NoClipboard

The script retrieves a temporary official history URL. It does not import
the complete history; paste the verified URL into the site's import form.
