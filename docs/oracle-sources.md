# 绳匠灵签：来源与规则

签文用于民俗娱乐；在游戏中选择不同站位、朝向或求得不同签文，不改变官方调频概率。

## 签谱

- 名称：《关圣帝君灵签》一百签。
- 底本：姑苏钮氏藏板《关帝灵签》清刊本。
- [维基文库转录目录](https://zh.wikisource.org/zh-hans/關聖帝君靈籤)。每签的具体来源、修订和校记保存在 `oracle-signs.json`，页面签谱详情与结果下方可查。
- [古籍扫描](https://zh.wikisource.org/wiki/File:關帝靈籤.姑蘇鈕氏藏板.清刊本.pdf)，文件说明链接到哈佛燕京图书馆的数字化藏本。
- 采用转录文本并对底本签号、等级及部分文字作核对，不能视作全书逐字精校本。扫描未标的等级按未标展示；已确认的异文在单签校记中说明。
- 原签诗与旧注属于历史文献；本站白话解签、地点关联及界面另行编写，并标注“本站整理 / 游戏趣味演绎”。原签文中对现实吉凶的表述属于历史民俗内容。

## 排盘

- 使用 [lunar-javascript](https://github.com/6tail/lunar-javascript) 1.7.7，MIT 许可。本地副本、许可和完整性记录见 `vendor/lunar/`。
- 支持公历、农历及有效农历闰月，出生日期范围为公历 1900 年 1 月 1 日至今天。
- 首版固定按东八区民用时间（UTC+8）处理。请填东八区钟表时间；不自动按出生地换算真太阳时，不自动还原历史夏令时。
- 年柱按立春交接时刻，月柱按节令交接时刻。日柱采用该库 sect=2：23:00 仍是当日日柱，00:00 换日柱；时柱依库的子时口径计算。
- 不知道时辰时，时柱留空。若该天正逢节令交接，无法确定的年柱或月柱会列出两种可能，标记为未定。
- 展示日干所属五行，不据五行个数推断喜用神，也不评判命格。

## 每日选签与地点匹配

这是本站公开的游戏娱乐规则，并非古签谱中已有的八字抽卡算法。

1. 求签日期跟随使用者设备时区，界面标注“当地时间”，以当地零点划分每天。生辰转换为对应公历日期与填写时间（未知时辰使用未知标记），加上当地当天日期与算法版本，采用固定散列映射到百签。页面定期检查日期，返回页面时也会刷新；跨日后保留已展示的签文并提示重新求签。
2. 一样的出生资料在同一天得到相同签文。通用签只依当天日期生成。切换已解锁城市只影响地点，不改变签文。
3. 城市地标的“木、火、土、金、水”是本站依据环境意象制定的标签，不是游戏官方属性。
4. 地标元素与出生日干元素相同加 2 分，与当天日干元素相同加 1 分；同分按固定的每日顺序排列，最多推荐 3 处。通用签只计算当天元素。
5. 分数用于解释候选排序，不是幸运值、成功率或出金率。选签不会根据充值、抽卡次数或真实账号数据改变。

## 城市地点

当前收录六分街、光映广场、芭莱大厦前、黑雁工地旧址、斯科特哨站、野火镇、厄匹斯港、H.A.N.D.总部、澄辉坪、泅珑围、绮梦度假村、布亚斯特城区和维尔乌姆城区的步行地标。

随便观归在澄辉坪，贝克福德街和齿轮街归在布亚斯特城区。布亚斯特随第三季第一章解锁，解锁该城区即可前往 3.1 新增的齿轮街。足球场点位取自玩家的齿轮街探索记录。[3.0 官方公告](https://www.taptap.cn/moment/816024102270667939) · [3.1 官方公告](https://zzz.mihoyo.com/news/165415) · [足球场位置](https://forum.gamer.com.tw/C.php?bsn=74860&snA=10670)

维尔乌姆城区在 3.2 加入，随第三季第一章解锁。收录的两处地点分别使用「弗林特工坊」和「熔光馆」传送点，后者可由馆内前往庭院绿雕。传送点需在玩家自己的地图中开放。[3.2 官方公告](https://zzz.mihoyo.com/news/166026) · [工坊传送点与熔光馆庭院路线](https://www.miyoushe.com/zzz/article/78153353)

绮梦度假村及其室内设施需推进相关剧情，H.A.N.D.总部收录室外广场。各点位卡可查阅路线与资料来源。

求签时可勾选已解锁的街区，也可以清空选择，只看签文。更改街区会重新排列地点，签号沿用当天的选签结果。

地点通过公开官方资料和社区游戏图文核对。当前未提供本站现场实測、实景截图或精确导航坐标；相对朝向是本站拟定的站位指引，不推断游戏世界的绝对东南西北。街区需玩家自行解锁，任务、时间与版本可能影响现场可达区域。

## 本地资料与分享

出生资料仅用于当前页面内存计算，不发送至服务器，不写入网址、不写入签簿。刷新后出生输入清空。

“收入签簿”为主动保存操作，仅保存求签时当地日期、签号与地点 ID，最多 30 条。此前已保存的记录保留原日期，不按新的时区重新计算。清理网站存储会清除签簿。“保存签卡”生成的图片只包含签文、求签时当地日期和主荐地点，不含生辰或四柱。

签谱与地点 JSON、排盘库均从本站本地文件加载。点击资料来源链接时会打开相应外部网站。
